# ClueCode releases

Signed, notarized macOS builds of ClueCode, Clueso's desktop app for driving coding agents (Claude Code, Codex, Cursor and more) on your own subscriptions.

**[Download the latest release](https://github.com/clueso-ai/cluecode-releases/releases/latest)**: open the DMG and drag ClueCode into Applications. Requires an Apple silicon Mac.

ClueCode updates itself from this repo. The source lives in a private Clueso repository; this one only holds releases.
